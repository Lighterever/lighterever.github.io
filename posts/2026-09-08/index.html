前端技术开发#

1. HTML文档基本结构与编写#

  • <!DOCTYPE>声明：位于文档最前面，告知浏览器文档使用的HTML规范。
  • 基本结构：
  • 开发工具：推荐初学者使用文本编辑方式（如VSCode）编写，以熟悉标签；之后可转为使用所见即所得工具（如Dreamweaver）。

2. 文本与段落标签#

  • 标题标签：<h1>~<h6>
  • 段落标签：<p>
  • 换行标签：<br>
  • 预排版标签：<pre>
  • 分区显示标签：<div>
  • 文字格式标签：<font>（用于设置文字大小、字体、颜色）

3. 列表标签#

  • 无序列表：<ul> + <li>
  • 有序列表：<ol> + <li>
  • 定义列表：<dl> + <dt> + <dd>
  • 列表嵌套：列表之间可以相互嵌套使用

4. 超链接标签 <a>#

  • 基本语法：<a href="链接地址" target="打开方式">热点文本</a>
  • 链接类型：
    • 链接到其他页面：<a href="目标文件.html">热点文本</a>
    • 链接到本页内锚点：<a href="#书签名">热点文本</a>
    • 链接到其他类型文件（如压缩包）
    • 链接到电子邮箱：<a href="mailto:邮箱地址">热点文本</a>
  • target属性：指定打开方式
    • _blank：在新窗口打开
    • _self：在当前框架打开
    • _top：在整个浏览器窗口打开
    • _parent：在父窗口打开

5. 表格标签 <table>#

  • 基本结构：
    • 表格：<table>
    • 行：<tr>（Table Row）
    • 表头：<th>（Table Header）
    • 单元格：<td>（Table Data）
  • 跨行与跨列：
    • colspan：跨列合并（横向）
    • rowspan：跨行合并（纵向）
  • 表格属性：border（边框）、width/height（宽高）、align（对齐）、bgcolor（背景色）、background（背景图片）
  • 表格结构标签：
    • <thead>：表头分组
    • <tbody>：表体分组
    • <tfoot>：表尾分组
    • <caption>：表格标题

6. 图像标签 <img>#

  • 基本语法：<img src="图片文件名" alt="简单说明" width="宽度" height="高度">
  • 其他属性：border（边框宽度）、hspace/vspace（水平和垂直空白）、align（对齐方式）
  • 图像作为超链接：<a href="链接"><img src="图片"></a>
  • 图像热区：使用 <map> + <area> 在图像上定义可点击区域

7. 多媒体标签#

  • 背景音乐：<bgsound src="声音文件" loop="播放次数">（注：仅部分旧版浏览器支持）
  • 音频标签：<audio controls src="音频文件"></audio>
  • 视频标签：<video controls width="宽度" src="视频文件"></video>
  • <video>常用属性：controls（显示控制条）、autoplay（自动播放）、loop（循环播放）、muted（静音）
  • 页面自动刷新：<meta http-equiv="Refresh" content="秒数; url=新页面">

8. 框架应用#

  • <iframe> 标签：在页面中嵌入另一个页面
  • 结合超链接的 target 属性：通过设置 target="iframe的name属性值" 实现框架间的链接跳转

9. DIV+CSS布局#

  • 使用 <div> 标签结合 CSS 技术进行页面布局
  • .class（类选择器）：可复用，多个元素可共用同一个类名，用 .类名 在CSS中选中
  • #id（ID选择器）：唯一标识，一个页面中一个ID只能对应一个元素，用 #ID名 在CSS中选中
  • 两者区别：
    对比Class（类）ID
    唯一性可重复使用同一页面只能出现一次
    优先级较低较高
    适用场景多个元素需要相同样式单个元素的专属样式或JavaScript钩子
    命名规则.类名 { }#ID名 { }
  • <div> vs <span>：
    • <div>：块级元素，独占一行，常用于页面分区、布局
    • <span>：行内元素，不换行，常用于包裹文本片段设置样式

10. 表单标签 <form> ⭐（CTF常见考点）#

  • 基本语法：<form action="提交地址" method="提交方式">...</form>
  • 关键属性：
    • action：数据提交的目标URL
    • method：提交方式（GET 或 POST）
  • 常用表单控件：
    • 单行文本框：<input type="text" name="用户名" value="默认值">
    • 密码框：<input type="password" name="密码">
    • 单选框：<input type="radio" name="性别" value="男">（同name为一组）
    • 复选框：<input type="checkbox" name="爱好" value="篮球">
    • 下拉列表：<select name="城市"><option value="广州">广州</option></select>
    • 文本域：<textarea name="简介" rows="行数" cols="列数"></textarea>
    • 隐藏域：<input type="hidden" name="token" value="xxxxx">（⚠️ CTF常见：隐藏字段可能存放敏感信息）
    • 提交按钮：<input type="submit" value="提交">
    • 重置按钮：<input type="reset" value="重置">
    • 普通按钮：<input type="button" value="点击"> 或 <button>点击</button>
  • GET 与 POST 的区别（重点）：
    对比GETPOST
    数据位置URL地址栏中（?key=value）请求体中
    数据大小限制有（约2KB）无限制（通常由服务器配置）
    安全性低（数据暴露在地址栏）相对高（不暴露在URL中）
    缓存会缓存不会缓存
    用途获取数据提交数据
    • CTF考点：GET参数在URL中可见，POST参数需要抓包（如Burp Suite）才能查看

11. 注释与特殊字符#

  • HTML注释：<!-- 注释内容 -->（浏览器不显示，但可在源代码中看到）
  • 常见特殊字符：
    • ：空格（&nbsp;）
    • <：小于号（&lt;）
    • >：大于号（&gt;）
    • &：与符号（&amp;）
    • "：双引号（&quot;）
    • ©：版权符号（&copy;）
